## 已完成
### 共享像素引擎 `src/shared/pixel/`（API 只增不改，B/C 可放心用）
- `cat.ts`：16×16 猫（奶油身体、软黑描边、涂鸦的闭眼、ω 嘴、粉内耳、腮红、尾巴粉环）。分层组合（头/眼/嘴/身/腿/尾）。
  `catSprites()` 旧字段 `idle/walk/jump/bang` 不变，新增 `fall land back(2帧) happy(2帧) look sit sitAlert heart`；
  `catFrame(sp, body, t, landT)` 自动选帧；`CAT_FRAMES`（原始字符画，给审稿工具）。
- `sprite.ts`：新增 `compose()`（叠层）、`outline()`（自动 1px 描边）、`mirror()`、`recolor()`、`silhouette()`。
- `particles.ts`（新）：池化精灵粒子（重力/阻力/摆动/末尾闪烁消失，无透明度 = 像素干净）。
- `tiles.ts`：新增 `setTile()`（运行时改瓦片）、`landOn()`（移动/实体单向平台：云、弹簧）。
- `screen.ts`：新增 `configure()`（运行时改 minW/minH，竖屏/横屏切换）。
- `input.ts`：新增 `reset()`（失焦/切后台/过场时释放全部按键，也清触屏按钮状态）；`touch.ts`：释放隐式 pointer capture（滑动换向更稳）、阻止 iOS 双击缩放。
- `tools/pixel/sheet.ts`：`npx tsx tools/pixel/sheet.ts` → `review/sprites/*.png`（8× 联系表：cat、meadow-tiles/sprites/big/deco）。
- `tools/pixel/shot.mjs`：确定性截图（`window.__pause/__steps` + 按住按键）。先 `node tools/serve.mjs dist 8811`。

### 第一章 `src/stages/meadow/`
- `level.ts`：关卡生成器（200×15 格，地面第 12 行），输出字符地图 + 实体 + 装饰。节拍：
  1. 起点：猫坐着 → 头顶 "!!" → 起身（标题卡后）。路牌、第一个 ? 砖、小台阶、小水塘（2 格）。
  2. ? 砖区：普通爱心砖、**5 连击**爱心砖、**害羞砖**（第一次顶它会"!!"往右溜一格，再顶给大爱心）、**隐形砖**（猫里奥梗：空中顶出 "!!" + 大爱心）。
  3. 台阶 → 蘑菇草地：两只慢吞吞的蘑菇（踩 = 变成爱心；侧碰 = 轻轻弹开，不扣任何东西），两根管子。
  4. **瞌睡蘑菇**（冒 z）：猫靠近 → "!!" 惊醒 → 一路狂奔跳进高管子；之后猫站上那根管子，它探头送 3 颗爱心。
  5. **湖 + 笑脸云**：两朵会上下/左右漂的笑脸云（踩上去会眨眼）。
  6. 铃铛检查点 → **假地砖**：站上去 "!!"，地砖掉下去露出弹簧，把猫弹上高空的一串爱心。
  7. 砖路（顶上有高处大爱心 ?）、木板单向平台、更多蘑菇、3 格水塘、石头小山、第二个铃铛。
  8. **喷泉广场**：路灯、长椅、花坛。猫经过喷泉 → 锁输入 2.3 s（猫开心蹦跳、镜头居中）→ 喷泉持续 ~6.6 s 喷红色像素爱心（喷口主喷流 + 碗沿侧喷 + 全屏"爱心雨"（屏幕空间，铺满任何尺寸）+ 开场 56 颗环形爆发），HUD 计数在 4.2 s 内滚到 **200**；3.4 s 时浮现 "第 200 天 / 每一颗，都是给你的。"；之后喷泉一直轻轻冒心。
  9. **门**：猫靠近时门 "!!" 一下、蹦蹦跳跳往右挪 6 格（猫里奥梗，只一次）；再走近门会开缝透暖光；走到门中央 → 猫背影走进门 → 门关 + 爱心 → 像素光圈收拢到门 → `go()` 到 `/shop/`（`prefetchNext()` 提前预取）。
- 无死亡：掉水 = 水花 + 在最后的安全地面闪烁重生；同一水塘掉 3 次 → 铺一排爱心砖桥。
- `game.ts`：物理/实体/渲染。静态地形+装饰预渲染成一张 3200×240 离屏图，每帧按可见窗口 blit；水、砖块、粒子动态绘制。视差：天空渐变、6 朵大云（有的带睡脸）、两层远山。
- `main.ts`：页面外壳——chrome（中/EN、声音）、标题卡、HUD（像素爱心 + 三位计数，站点衬线字体）、首屏提示（移动后淡出）、喷泉字幕、重玩时左上"跳过"（`gift.progress ≥ 1`）、竖屏 minW 224 / 横屏 288。
- `sfx.ts`：全部合成音效 + 一首 C 大调小循环曲（方波旋律 + 三角波低音），默认静音，右上角开声音后才响。
- `art.ts`：全部瓦片/精灵/装饰的字符画生成器（~30 色调色板 PAL），`SHEETS` 给审稿工具。
- 竖屏手机：画布铺满，世界抬到触屏按钮上方（`padBottom()`），世界下方继续画泥土；上方是天空和云。横屏：按钮叠在地面上。
- dev：`?skip`（跳过标题卡）、`?at=lake|spring|bricks|hill|plaza|fountain|exit`、`?dev`（左下 FPS/坐标/粒子数），`window.__meadow` 调试对象。
- 体积：meadow JS 16.5 KB gzip（+ cat 4.7 KB + transition/i18n 2.8 KB），远低于 60 KB 预算。
