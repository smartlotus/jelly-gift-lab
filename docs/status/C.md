## 时间线（距离 或 时间，先到先触发 → 不操作也会全部发生；任何情况下 ≤ ~58 s 被抓）
| 触发 | 事件 |
|---|---|
| 开始 | 标题卡；点开始 → 1.1 s 录像开机（雪花→画面，STBY→REC），提示「按住屏幕前进 · 拖动环顾」（6 s 不动再出现） |
| d 11 / 24 / 33 | 路边红蘑菇（果冻页彩蛋伏笔）/ 木牌「别回头」/ 山坡上的粉色方块 |
| d 40 或 t 26 | 左前方树间闪过黄色 "??"（1.4 s）+ 沙沙声 |
| d 48 或 t 32 | 火把熄灭（0.12 s 闪 + 0.6 s 黑），画面噪点变大 |
| d 58 或 t 38 | 前方 15 格处一个方块大身影横穿小路，中途停下"看"你一眼（眼睛亮），蟋蟀停、萤火虫慢慢消失 |
| d 67 或 t 43 | 身后 17 格出现跟随的猪（回头能看到两点红光），沉重脚步、低沉"哼" |
| d 74 或 t 47 | 「跑！」自动奔跑（≥ 4.2 格/s，约 8 s 到死路）、镜头抖、心跳、电量闪、红色调；猪逐渐逼近到 3 格 |
| 到 d 115.6 | 「没路了……」铁栏门；1.5 s 后强制转身 180°（0.48 s），猪脸贴屏 0.25 s（火把从下方照亮、红眼）→ 雪花撕裂 0.35 s → **同一帧硬切**到粉嫩贴纸（不透明 DOM，无白闪），随后销毁 WebGL |
| 反转后 | 「继续 →」/ Enter / 12 s 自动 → 粉色光圈 → `go('jelly')` |

## 操作
- 触屏/鼠标：**按住任意位置 = 前进**，按住时拖动 = 环顾（松手 1.2 s 后视角慢慢回正）。
- 键盘：W / ↑ / 空格 前进；A/D 或 ←/→ 转头；S/↓ 回头。
- 追逐阶段自动奔跑，无需操作。

## dev 参数
`?skip`（跳过标题卡）、`?at=chase`、`?at=caught`（直接到死路→被抓）、`?at=kawaii`（直接看反转）、`&stay`（反转不自动跳转）、`?d=20`（从第 20 格开始）、`?dev`（FPS/d/t/phase）。截图：`window.__pause=true; window.__steps=N`；脚本 `node review/stage3-night/shoot.mjs <url> <out.png> [w h steps mobile]`（需 `npx vite preview --port 8822`）。
